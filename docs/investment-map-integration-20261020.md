# 投资图谱融合记录

参考：用户提供的本地《投资大师知识图谱.html》。原文件保留原样，不作为线上依赖。

## 已融合

- 人物、思想、书籍和行动的连接；八位人物各有核心观点、实践、适用边界和核对入口。
- 18 个思想概念及其跨人物关联，接入现有八条投资知识主线与 24 本详细书籍笔记。
- 人物聚焦、共享思想全景、概念与人物双向跳转；原有知识主线和书籍锚点继续可用。
- 延伸资料包含《穷查理宝典》《够了》《战胜华尔街》《原则》、经济机器教学资料、段永平公开问答与索罗斯反身性讲座。延伸资料不计入 24 本完整书籍笔记。
- 企业价值、指数配置、周期反馈、规则交易四类方法对照，附证据要求与常见混淆。
- “说得清、经得起检验、迁移得了、允许纠错”四项学习标准。

## 内容调整

- 不继承参考页的个人排名、入选与排除结论，也不将人物划分为普通人可学或不可学。
- 人物与概念关系明确标为编辑整理；未列关联不表示该人物不讨论它。
- 安全边际不固定为某个折扣；周期不写成固定年数；分散不承诺固定数量的资产就能降低风险。
- 区分逆向思考与逆向投资；不把护城河简化为管理层可被随意替代。
- 不将多年费用简单相乘当作终值损失；练习要求比较复利终值并说明假设。
- 不把整理问答当作本人撰写的系统教材，不把主题对读书籍误标为人物本人著作。

## 实现

使用 Nunjucks 静态输出和现有原生脚本，页面不请求 Vue 或其他在线组件。无脚本时全部人物与全景仍可读；脚本启用后提供筛选、自动展开和定位。新增数据分别位于 `src/_data/investmentMasters.json` 与 `src/_data/investmentIdeas.json`，主题资料链接随条目呈现。
